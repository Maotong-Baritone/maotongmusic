## 怎么审核

1. 双击项目根目录的 `启动管理工具.bat`。已打开的旧版后台需要先关闭，再重新启动。
2. 登录后点击“勃拉姆斯预审”，或打开 <http://127.0.0.1:5000/import-review/brahms>（若修改过后台端口，请使用该端口）。
3. 默认进入“规则样例”：先看 20 条代表性记录，涵盖完整作品、单乐章、独唱、艺术歌曲重唱、曲集、分谱、总谱、本人改编、选段和移调版本。确认按钮仅记录这组整理风格，**不批准任何文件**；样例内容变化后需重新确认。
4. “按作品查看”：先选作品（例如搜索 `Op. 116`），再展开乐章与版本。只有同一乐章、相同编制/调性/语言及兼容来源说明的版本才提供共同信息修改；不同乐器声部、调性与改编者分组保留。分组不删除、不合并 PDF。保存前明确列出受影响的文件，旧页面提交遇到内容变化会停止写入。
5. “集中处理疑点”：按标题范围、调性、重复来源和许可附注等分组。暂时不处理的整组可以设为“暂缓”，不删除；在暂缓列表进入单条编辑或批量状态设置，可恢复待审核。同一文件可能有多个问题，各组计数不能相加。
6. “逐文件编辑”保留原有详细表单。修改后点“保存这一条”；该页面的批量操作只修改状态，不保存其他尚未提交的字段。
7. 只有你确认的文件才设为“批准”。所有审核操作仅写入本地清单，不会开始下载或发布。

审核结果保存在本目录 `manifest.json`，不要删除该文件。`review_catalog.csv` 是生成时的导出快照，不是审核数据库；在 CSV 中修改不会写回页面，页面修改后需刷新导出才能体现在 CSV 中。

## 标记约定

- 完整作品保留总标题和作品号，例如 `7 Fantasien, Op. 116`。
- 单乐章以乐章名为标题，例如 `No. 1 Capriccio. Presto energico, Op. 116`；“所属作品”保留总标题。
- 多首选段写明编号范围；同一乐章拆分的文件注明片段编号。
- 编制使用中文简写，如“钢琴独奏”“声乐、钢琴”“小提琴分谱”。器乐的歌词语言留空。
- “艺术歌曲”分类不再重复加同名子分类。
- 按用户确认的规则，不新增“声乐重唱”分类。艺术歌曲的重唱归入“艺术歌曲”，编制标为“二重唱、钢琴”“四重唱”等；真正的合唱编制（包括合唱改编版）及宗教声乐保留相应分类。
