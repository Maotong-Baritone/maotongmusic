# 大型乐谱的原文件备份与恢复

网页部署包仅含公开网页资源，PDF 由 R2 提供。乐谱原件保存在本地 `scores/`，供后台预览、校验及同步。Git 跟踪目录、对象键、文件大小和 SHA-256，乐谱原件按 `.gitignore` 单独管理。

在新克隆中运行本地后台前，请先从本地备份复制 `scores/`。个别缺失的已发布乐谱可以用下面的工具从 R2 恢复；已从 R2 删除的下架谱请从本地回收站备份恢复。

以《舒曼常用艺术歌曲教学曲选》为例，原 PDF 为 164,875,875 字节，保存在用户来源文件夹、本地 `scores/` 和 R2。

- public_id：`2ba98d71-a3f3-56c0-9a9d-6c8c07254d99`
- 本地目录：`scores/乐谱书/曲集/2ba98d71-a3f3-56c0-9a9d-6c8c07254d99.pdf`
- SHA-256：`1f8a6abe57b58620a2d9128898e289d9aa8f83558e26eaf8e5dbbfbe904f02af`

新克隆仓库缺少该文件时，可从公开对象存储恢复；请在严格目录检查前执行：

```powershell
.\.venv\Scripts\python.exe -X utf8 tools\restore_score.py 2ba98d71-a3f3-56c0-9a9d-6c8c07254d99
```

恢复工具只处理指定条目，核对完整文件大小、PDF文件头和SHA-256后才写入正式路径，
不会覆盖不同内容的已有文件，也不需要存储账户凭据。原PDF可由网站正常下载。

多国选集确有不同歌词语言时，使用“多语种”选项；书中只有中文导读或译释，
并不据此把单一原词语言改为多语种。不同声部、移调及选编版本继续分别著录。
